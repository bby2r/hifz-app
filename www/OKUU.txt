ХИФЗ — Куран жаттоо колдонмосу (мобилдик пакет)
================================================

Бул папкада эмне бар:
  • index.html            — колдонмонун өзү (бүт Куран тексти + кыргызча котормо ичинде, офлайн иштейт)
  • manifest.webmanifest  — колдонмонун аты/иконкасы жөнүндө маалымат
  • sw.js                 — офлайн иштөө үчүн (интернетсиз текст ачылат)
  • icon-192.png / icon-512.png — колдонмонун иконкасы

Эскертүү: Куран тексти жана котормо файлдын ичинде — интернетсиз көрүнөт.
Бир гана кыраат (аудио) үчүн интернет керек. Бир жолу уккан аяттын үнү кэшке
сакталып, кийин офлайн да угулат.

--------------------------------------------------
APK кылуунун жолдору
--------------------------------------------------

★ 1-жол — ЭҢ ОҢОЙ (компьютерсиз, кодсуз):
   Онлайн "website → APK" куруучуларынын бирин колдон:
   мисалы  websitetoapk.com  же  appsgeyser.com
   1. Сайтка кир, "HTML / Website" тандап,
      бул папканы .zip кылып жүктө (же index.html'ди жүкт).
   2. Колдонмонун атын "Хифз" кой, иконкага icon-512.png тандо.
   3. "Build / Create APK" бас — даяр APK'ны жүктөп ал.

★ 2-жол — PWA катары (APKсыз эле телефонго орнотуу):
   1. Бул папканы кандайдыр бир хостингге кой (мис. Netlify Drop:
      app.netlify.com/drop — папканы сүйрөп таштасаң эле болот).
   2. Чыккан шилтемени телефондо Chrome менен ач.
   3. Меню (⋮) → "Башкы экранга кошуу / Install app".
      Колдонмо иконка болуп орнойт, толук экран, офлайн иштейт.
   4. Ошол эле шилтемени  pwabuilder.com  сайтына берсең,
      даяр .apk / .aab (Google Play үчүн) жасап берет.

★ 3-жол — Программисттер үчүн (Capacitor, компьютер менен):
   npm i -g @capacitor/cli
   npm create @capacitor/app  (же бар долбоорго кош)
   www/ папкасына ушул файлдарды көчүр → npx cap add android
   → npx cap sync → npx cap open android → Android Studio'дон APK чыгар.

Суроолор болсо кайрыл — жардам берем.
